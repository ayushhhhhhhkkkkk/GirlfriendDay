# Bebu & Bebudi — Girlfriend's Day Site

A tiny personal website: hero page → 5-second countdown → love letter with your photo → a "free hug & kisses" coupon page. Background music plays throughout.

## How to put this on GitHub Pages (free hosting)

1. Go to https://github.com and create a free account if you don't have one.
2. Click the **+** icon (top right) → **New repository**.
   - Name it something like `girlfriends-day` (this becomes part of the URL).
   - Set it to **Public**.
   - Click **Create repository**.
3. On the new repo page, click **uploading an existing file**.
4. Drag in all the files from this folder: `index.html`, `style.css`, `script.js`, and the `assets` folder (with `us.jpg` and `song.mp3` inside — keep them in an `assets` folder, don't drop them loose).
5. Click **Commit changes**.
6. Go to the repo's **Settings** tab → **Pages** (left sidebar).
7. Under "Build and deployment", set **Source** to **Deploy from a branch**, branch = `main`, folder = `/ (root)`. Click **Save**.
8. Wait ~1 minute, then refresh — GitHub will show your live link, something like:
   `https://yourusername.github.io/girlfriends-day/`
9. Send her that link!

## Notes
- Works great on mobile (that's how she'll likely open it).
- The music needs one tap to start (browsers block autoplay) — clicking "open it" on the first page starts it.
- Want to change the text later? Just edit `index.html` in GitHub directly (pencil icon on the file) — no coding tools needed.
